# Fase 1 — Bases Multimodais em Cardiologia

Esta fase reúne os materiais de base do projeto CardioAI para exploração multimodal em cardiologia, com foco em organização acadêmica, rastreabilidade e preparação para etapas posteriores de IA.

## Conteúdo da fase

- `frases_pacientes.txt`: frases clínicas simuladas para experimentos textuais
- `heart-explain.md`: material explicativo de apoio
- referências complementares em [`../../docs/references/`](../../docs/references/)
- referências bibliográficas gerais em [`../../referencias.md`](../../referencias.md)

## Objetivo

Organizar fontes e materiais que apoiem:

- análise de dados clínicos
- exploração de sintomas em linguagem natural
- documentação de contexto médico
- preparação para IA multimodal

## Organização recomendada de dados

Os dados do projeto devem seguir a estrutura da raiz:

- dados brutos em [`../../data/raw/`](../../data/raw/)
- dados processados em [`../../data/processed/`](../../data/processed/)
- amostras pequenas em [`../../data/samples/`](../../data/samples/)

## Como consultar

Abra diretamente os arquivos desta fase ou utilize os materiais de referência em:

```bash
code phases/fase01_bases_multimodais
```

## Observações

- Não versionar datasets grandes diretamente no repositório.
- Priorizar documentação de origem, contexto clínico e uso acadêmico responsável.
